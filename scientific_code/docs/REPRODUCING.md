# Reproducing the calculations

Run commands below from the repository root after installing `requirements.txt`.
Use the virtual-environment interpreter. The runner resolves its default paths
relative to the repository, so it can also be invoked from elsewhere.

## Task selection and outputs

```sh
python3 run.py --mode quick
python3 run.py --mode standard
python3 run.py --mode full
python3 run.py --mode full --list
python3 run.py --only tuned_branch_bvp test_tuned_branch_bvp
python3 run.py --output-dir /path/to/results --log-dir /path/to/logs
```

The default data directory is `results/data/`; the default log directory is
`results/validation/quick`, `standard`, `full` or `selected`, according to the
selection. Repeating a selection replaces its generated outputs and logs. Use
`--log-dir` and `--output-dir` to retain separate runs. Supplied scientific data
in `data/generated/` and historical logs in `validation/reference/` are not
regenerated by default.

Each run records the interpreter, package versions, platform, selected tasks,
timings and exit codes. An exit status of zero means all selected tasks passed;
it says nothing about omitted tasks. PASS-marker totals exclude uncounted
assertions and are not counts of independent methods. A nonzero task exit,
`[FAIL]` marker or timeout is a failure. `--timeout SECONDS` sets an optional
per-task limit. Do not use `-O` or set `PYTHONOPTIMIZE`.

Quick mode covers central results. Standard adds shorter exact controls,
failure-detection tests and the formal series comparison at powers 28 and 34.
Full also runs the expensive symbolic tensor and high-precision inward scans;
allow hours. The complete current full suite has not been timed or rerun. See
[validation coverage](VALIDATION.md) for the selections actually executed and
[the output map](PAPER_OUTPUTS.md) for individual paper results.

## Fixed-coupling families and numerical windows

The symmetric-model controls can be reproduced separately:

```sh
python3 run.py --only branch_trace fixed_coupling_control plot_branches --log-dir results/validation/fixed_coupling
```

`calculations/reversible_branches.py` implements scaled autonomous shooting
from the regular outer-horizon asymptote to the unique metric maximum. The
matching condition is the scalar value for odd modes and its derivative for
even modes. Reflection completes the second half. `fixed_coupling_control`
holds `nu` (and therefore the action coupling) fixed and solves for `phi_plus`.
`branch_trace` reads the same matching curve in the other direction, solving
for `nu` at prescribed amplitude. The charge normalization is
`V_eff=2*cosh(alpha*phi)` with `alpha**2=2*nu*(nu+1)` and `V_g=0`.

The trace contains 45 positive amplitudes from 0.05 through 6 for each of
`n=3,...,7`. It records the scalar zero count over the full open interhorizon
interval, matching residual and energy residual at every point. The separate
control reproduces fixed `nu=2.99`, the previously validated amplitude 0.2
solution, four exact A2 product controls, and three cutoff/tolerance settings
at each amplitude-6 endpoint. It also samples both reflection conditions at
`nu=2.5,2.9,2.99,3.01,3.5` over `0.005 <= phi_plus <= 6`, refining all detected
sign-changing brackets. Dividing the matching function by `phi_plus` excludes
the trivial RN zero-amplitude root.

Outputs are `branches/branch_trace.csv`, `branches/branch_trace.json`,
`branches/fixed_coupling_scan.csv`, `branches/fixed_coupling_control.json`, and
`figures/branches.pdf` (also PNG). The figure uses absolute `nu` with separate
upper-panel scales to resolve the narrow windows and a common lower-panel
scale for `eta`. Open zero-amplitude points are analytic limits; filled points
at amplitude 6 are finite samples. Its metadata records the trace checksum.

These calculations establish numerical evidence over the stated finite
ranges. They do not certify infinite-amplitude endpoints, maximum deficits,
global monotonicity, uniqueness, or absence of additional roots. A finite
sign-change scan can miss tangent roots or close root pairs. Nonreversible
branches, overlap at higher node number, and generic unequal exponential
slopes are not tested. Unequal charges with equal opposite slopes can be
absorbed into a scalar shift and scale; that is not a test of unequal slopes.
The separate exact B2 control is an asymmetric integrable benchmark only.

The supporting exact higher-mode calculation is also included as
`calculations/higher_modes.py`, retained from the validated scientific snapshot.
It computes the cubic regularity coefficient and independently
reconstructs the quartic metric response with rational arithmetic for every
`n=1,...,20`. The accepted results are in
`data/generated/higher_modes/higher_modes_results.tsv`, with source and result
checksums and historical provenance in the adjacent JSON file. They were
independently validated earlier and are not represented as a new 2 November
run. This potentially costly task is supplementary to quick and
standard modes, and is included in full mode:

```sh
python3 run.py --only higher_modes --log-dir results/validation/higher_modes
```

The runner records the exact TSV in its `higher_modes.log`. The calculation
establishes the checked finite set of signs, not a theorem for every mode.

To copy newly generated figures to a manuscript directory, use:

```sh
python3 run.py --only plot_orbit --paper-figures-dir /path/to/paper/figures
python3 run.py --only branch_trace plot_branches --paper-figures-dir /path/to/paper/figures
```

This option requires at least one of `plot_orbit`, `plot_branches`,
`plot_deficit` or `plot_families` in the selection and copies
the corresponding PDF only after its plot task succeeds. A copy failure makes
the task fail. Scientific outputs remain in `results/data/figures/`, and the
copied path is recorded in the task summary. Without this option, the runner writes
no manuscript files.

The high-order series comparison uses a newly generated amplitude scan in the
selected output directory when one is present; otherwise it uses the packaged
scan. Its `--table` option overrides that input. The program records the input
path and SHA-256 checksum, and explicitly checks all six manuscript table rows
at power 34 against empirical tolerances of `3e-13` in the coupling and `1e-13`
in the entropy product. Power 28 is retained as a truncation diagnostic; at
amplitude 0.3 its truncation partly cancels the packaged shooting error. The
25 October series validation checks both the packaged scan and a
freshly regenerated scan; platform-dependent floating-point variation remains
possible, and these tolerances are not accuracy certificates.

## Independence and provenance

The three interhorizon constructions use distinct numerical procedures:
global collocation, two-sided initial-value shooting, and reflection-based
half-interval shooting. Their boundary series and matching implementations are
separate. They solve the same physical equations, so this independence concerns
numerical construction, not physical assumptions. Exact dilaton and
Reissner–Nordström fields, unused constraints, off-mesh residuals and curvature
checks supply additional tests.

The exterior orbit implementation uses a **fresh half-interval solution** for
its coupling and inner radius, recorded in `orbit_metadata.json`; it does not
silently reuse a hard-coded tuned seed. Its differential equations and
compactified endpoint treatment are implemented separately from the interior
solvers. The orbit's entropy product is an exact translation invariant, so
agreement between orbit members is a consistency check.

The coupling/low-order series control derives the first additional
coefficients with SymPy, separately from the general series recurrence. The
exceptional obstruction control constructs exact sources with standard-library
rational arithmetic. The B2 control substitutes the closed form into all
reduced equations and compares a separate numerical IVP with those fields; it
does not extend the symmetric tuned-branch BVP solver to unequal couplings.
The general translation control checks geometric, constraint and charge
identities for the static neutral-scalar, abelian sector with zero scalar
potential, and includes exact singular-endpoint flux examples.

`controls/series_fraction_comparison.py` reproduces the formal tuned-branch
recurrence with the portable `fraction_polynomial.py` helper. It is a separate
arithmetic implementation of that recurrence, not an independent high-order
derivation. It prefers `results/data/branch/amplitude_scan.csv`, falls back to
the supplied
`data/generated/branch/amplitude_scan.csv`, and writes
`results/data/controls/series_comparison.csv` by default. It compares powers 28
and 34 with the unrounded shooting data and applies the manuscript agreement
assertions at power 34; the low-order SymPy calculation and
numerical shooting provide separate comparisons. Agreement and order changes
do not certify a convergence radius or a truncation bound. No Sage or
python-flint dependency is introduced.

Assertions against rational constants in `quartic.py`, and comparisons against
stored numerical reference values in `validate_core.py` and other scripts,
are **regression guards**. They are not counted as independent derivations.
The quartic program performs exact polynomial arithmetic, while the numerical
amplitude scan provides a separate small-amplitude comparison. Refinement
spreads and endpoint estimates are empirical diagnostics, not certified error
bounds or computer-assisted existence proofs. The local existence theorem,
global hypotheses, and limitations are established or stated in the paper.
